# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this website or the Leapath platform,
please report it responsibly:

**Email:** info@leapath.tech  
**Subject:** `[SECURITY]` followed by a brief description

Please do not open a public GitHub issue for security vulnerabilities.

We will acknowledge your report within 48 hours and aim to release a fix within 7 days for critical issues.

## Scope

- `https://www.leapath.tech` and all subdomains
- The Leapath web application and API

## Out of Scope

- Denial of service attacks
- Social engineering
- Physical security
